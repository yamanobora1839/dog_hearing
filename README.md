# dog_hearing

スマートフォン向けの、犬の聴覚の目安を紹介するオフラインWebアプリです。

## 特徴

- HTML / CSS / JavaScriptのみで構成
- Web Audio APIの `OscillatorNode` を使ってブラウザ内で正弦波を生成
- 周波数を10Hz～25,000Hzの範囲で対数的に調整
- 再生中もスライダー操作で周波数を連続変更（オシレーターを維持）
- 人間と犬の一般的な可聴域の目安を比較表示
- ページを離れる・バックグラウンドになる・ウィンドウがフォーカスを失うと停止
- 外部ライブラリ、サーバー、API、音声ファイルを使用しない

## ローカルでの確認

静的なWebサーバーを起動するか、ファイルをブラウザで開いて利用できます。
ローカルサーバーの例：

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## GitHub Pagesで公開

1. リポジトリの `Settings` を開く
2. 左メニューの `Pages` を開く
3. `Build and deployment` の `Source` を `Deploy from a branch` に設定
4. ブランチを `main`、フォルダーを `/ (root)` に設定
5. `Save` を押す

公開URL: https://yamanobora1839.github.io/dog_hearing/

## 注意

人間・犬の可聴域の数値は一般的な目安で、年齢、犬種、個体差や音量などによって異なります。周波数を生成できても、スマートフォンのスピーカーから十分な音量で再生されるとは限りません。特に低音や高音は、機種によって再生が難しい場合があります。
